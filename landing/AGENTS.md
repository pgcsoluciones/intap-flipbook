# Instrucciones para Codex - Landing

Codex solo debe trabajar dentro de esta carpeta: /landing.

No modificar archivos fuera de /landing sin autorización explícita.

Objetivo:
Crear una landing page moderna, responsive y limpia para el proyecto INTAP Flipbook.

Reglas:
- No tocar backend.
- No tocar archivos de configuración global fuera de /landing.
- No modificar el trabajo del otro desarrollador IA.
- No instalar dependencias sin explicar primero para qué son.
- Antes de cambios grandes, presentar un plan.
- Después de cada tarea, indicar qué archivos fueron modificados.
- Priorizar diseño responsive para móvil.
- Mantener código simple y fácil de mantener.
